# DataForge – AI Teaching Agent & Data Science Learning Platform

> A problem-first Data Science learning platform with an adaptive Socratic AI Teaching Agent, real-world project datasets, and skill scaffolding.

---

## 📖 Documentation
- **[Product Requirement Document (PRD.md)](./PRD.md)**: Comprehensive PRD specifying system architecture, the 6 Teaching Agent roles, 16 core skills, 15 tools, 12 flagship projects, API contracts, database schema, and roadmap.

---

## 🌟 Core Pillars
1. **Real-World Problem Scaffolding:** 12 industry projects across 8 tracks (Predictive Modeling, NLP, Computer Vision, Forecasting, BI, Data Engineering, MLOps, A/B Testing).
2. **Socratic AI Teaching Mentor:** Delivers multi-tiered hints, custom learning roadmaps, anti-data-leakage checks, and code quality reviews.
3. **Curated Taxonomy:** Explicit mapping across 16 core data skills and 15 industry tools.
4. **Modern Architecture:** Built with Next.js, Three.js 3D network graph, Supabase PostgreSQL with Row Level Security (RLS), and Claude/Gemini API endpoints.
